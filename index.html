Welcome

About the Product

A web game where pupils rescue Malaysian animals by fixing English sentences muddled by Bahasa Melayu patterns.

LearnersYear 3 ESL pupils (CEFR Pre-A1 to A1)
SkillsReading (LS 3.2.2) and Writing (LS 4.3.3)
TopicAnimals and their habitats
AimReduce BM-to-English transfer errors

Every mission: Read → Notice → Fix → Write

1📖Read

Read an animal report and answer detail questions.

2🔍Notice

Compare BM and English and spot the mix-ups.

3🔧Fix

Repair muddled sentences with 3-level hints.

4✏️Write

Write own sentences with instant feedback.

Four missions, four mix-ups

Ellie the ElephantCopula beThe elephant is big.
Rimau the TigerSubject–verb agreementHe eats meat.
Utan the OrangutanArticles a / an / theHe is an orangutan.
Tutu the TurtlePrepositions in / on / under / atTutu swims in the sea.

Identified gap

📍 Now

  • Rely on BM sentence patterns
  • Cannot see how BM and English differ
  • Get feedback late, so errors become habits

🎯 Needed

  • Notice the BM–English difference
  • Fix errors in context, with quick feedback
  • Write accurate simple sentences

How to use

🧒 Pupils

  1. Open the link or scan the QR code.
  2. Type a nickname and pick a buddy.
  3. Do Ranger Training, then the 4 missions.
  4. Finish the Final Challenge and get a certificate.

🧑‍🏫 Teachers

  1. Choose "I am a teacher" and create a PIN.
  2. Read the Lesson Guide.
  3. Open Class Results to see every pupil's scores (online scoreboard).
  4. Export the CSV.
